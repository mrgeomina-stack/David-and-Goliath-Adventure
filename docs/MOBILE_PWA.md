# Mobile, tablet and installable web edition

The five original games, illustrated scenes, story order, keepsakes, Arabic/English
captions and 30-second activity challenges remain intact. The world keeps its 1280×720 coordinate
system and fits inside the available screen without cropping. Controls and readable
cards scale independently on smaller screens, with 44 CSS-pixel primary targets.
Safe-area padding protects iPhone cutouts and Home indicators. Dynamic viewport
height accounts for Safari/Chrome toolbars.

## Play on a phone or tablet

Use the hosted HTTPS game address in Safari on iPhone/iPad or Chrome on Android.
Turn the device sideways. Portrait phones offer a rotation reminder and pause an
active game; returning to landscape resumes it. Continuing in portrait is optional,
but landscape provides more room. Tablets may remain in portrait with letterboxing.

All five activities share the **right-side concentric-circle joystick**. Drag
its gold inner circle and release to centre it; contextual action buttons sit
above it. See [the full joystick guide](JOYSTICK_CONTROLS.md).

- Sheep: steer David, tap a nearby sheep once to lift it, then steer through the
  pen entrance. The 30-second challenge and untimed Free Play remain unchanged.
- Maze/return to Saul: steer through the real corridors or toward Saul. Keyboard
  arrows/WASD and maze swipes still work.
- Armour: steer the hand, Pick a piece, steer it onto the correct body part and
  Place it. Direct finger dragging and tap-piece/tap-body also work.
- Brook: steer the hand and Scoop, or tap a smooth stone, **while the moving ring
  overlaps it**. Early/late attempts miss; the ring never pauses.
- Sling: pull and hold the circle, then release to throw. The action button and
  SPACE also work. Cancelled gestures do not throw. Actual collision determines
  the outcome.

All navigation, colourful instructions, celebrations, music and optional local
narration remain available. Audio unlocks from a gesture; missing installed voices
leave captions available. Keyboard and mouse continue to work.

## Install and save for offline play

1. Open the hosted HTTPS link online. On iPhone/iPad use Safari's Share menu → Add
   to Home Screen. On Android use Chrome's Install app/Add to Home screen, or the
   game's ＋ button if the browser offers the native installation prompt.
2. Open the installed app online and open **Book**. Choose **Save for offline play**,
   then wait until **Offline ready**. Offline saving is optional in the Pages build.
   Safari can give the Home Screen app its own storage, so check inside that app.
3. Then the complete game works offline, including artwork, animations and locally
   synthesized sound. Earned keepsakes remain in that browser/app's local storage.

The web build contains approximately 70.5 MiB of local artwork, fonts, audio and
code before transfer compression. Offline saving requires device storage in
addition to normal browser memory. A failed required download shows a retry
control and never announces readiness for an incomplete cache. Device storage
cleanup, private browsing or removing site data can remove offline availability
and local keepsakes; reconnect and save again.

Updates download to a separate complete cache. They wait until **Update adventure**
is chosen in the book and confirmed. Updating reloads the current mission and keeps
earned keepsakes. There is no forced reload during a mission.

## Publish the prepared static web build

Use **Davids_Big_Adventure_Cloudflare_Pages.zip** or **pages-dist/**, generated by
`npm run build:pages`. All assets are local, with no individual file over 25 MiB.
Read [the step-by-step Cloudflare Pages Free guide](CLOUDFLARE_PAGES_FREE.md) for
folder upload, GitHub build settings, installation and production preview.
Do not upload the old Web/Offline ZIPs: their all-in-one HTML exceeds the limit.
No public deployment has been performed.

## Implementation and evidence

`src/mobile.ts` handles fit and the Canvas roundRect fallback; `src/touch.ts`
normalizes coordinates and manages independent captured pointers, cancellation
and swipes. `src/main.ts` provides responsive HTML controls, rotation and safe
focus handling. `src/pwa.ts` manages readiness, installation guidance and explicit
updates. `scripts/pages-worker.js` caches the complete local asset set on explicit opt-in,
with a content-derived version generated by `scripts/pages-build.mjs`. The separate
standalone build retains `public/sw.js` and `scripts/offline.mjs`. Scope-relative URLs support subdirectories.

Run `npm test`, `npm run build:pages`, then `npm run test:pages`. The suite includes
native emulated touch at seven phone/tablet sizes, multi-touch gameplay, actual
service-worker caching, an interrupted asset download/retry, offline reload/new-tab
launch, real offline maze completion and update persistence. See [PAGES_TEST_REPORT.md](PAGES_TEST_REPORT.md)
for measured results and the physical-device/Safari checks still outstanding.
